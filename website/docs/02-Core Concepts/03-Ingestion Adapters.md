# Ingestion Adapters

AgentDiff is designed to be telemetries-agnostic. It normalizes external telemetry logs from popular LLM observability tools into a canonical `AgentTrace` DAG format.

## Trace Loader & Auto-Detection

The easiest way to load a trace is using the `load_trace()` function. By default, it auto-detects the source format:

```python
from agentdiff import load_trace

# Auto-detects the format (DeepEval, Langfuse, OTel, or Generic)
trace = load_trace("run_data.json")
```

You can also force a specific adapter by passing the `adapter_name` parameter:
```python
trace = load_trace("run_data.json", adapter_name="deepeval")
```


## Supported Adapters

### 1. Generic Adapter (`generic`)
Used for custom JSON traces that match the AgentDiff canonical schema directly. It maps Pydantic models `AgentTrace` and `TraceStep` 1-to-1.

### 2. DeepEval Adapter (`deepeval`)
Parses nested trace trees from **DeepEval** evaluations. It processes hierarchical span chains, maps token count metrics, calculates latencies, and flattens the tree into canonical steps.
* Maps `TraceType.TOOL` and `TraceType.RETRIEVER` to `StepType.TOOL_CALL`.
* Maps `TraceType.LLM` to `StepType.LLM_CALL`.
* Maps nested `spans`, `nodes`, or `children` arrays recursively.

### 3. OpenInference / OpenTelemetry Adapter (`openinference`)
Parses standard OTel span collections generated by instrumentation backends (e.g. Arize Phoenix, Traceloop).
* Identifies root spans based on empty `parent_span_id`.
* Extracts OTel attributes prefixed with `openinference.span.kind`, `input.value`, and `output.value`.
* Maps LLM token metrics (`llm.token_count.prompt`, `llm.token_count.completion`).

### 4. Langfuse Adapter (`langfuse`)
Parses exported JSON observations dumps from Langfuse.
* Maps `type: "GENERATION"` to `StepType.LLM_CALL`.
* Maps `type: "SPAN"` containing "tool" in its name to `StepType.TOOL_CALL`.
* Parses `startTime` and `endTime` ISO timestamps to determine duration latencies.
